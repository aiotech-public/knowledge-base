# BI Builder — свой дашборд из виджетов

**BI Builder — это конструктор кастомных дашбордов: собираешь свою страницу из чарт-виджетов поверх метрик тенанта, раскладываешь их по сетке и разбиваешь по табам.** В отличие от штатного `Dashboard` (`/app/dashboard` — фиксированная сводка по тенанту, см. [reference/ui-map.md](../reference/ui-map.md)), тут раскладку, набор чартов, метрики и группировки задаёшь сам.

Открывается из меню `Analytics → BI Builder`, роут `/app/analytics/bi-builder`. Доступ управляется permission `analytics.charts-builder` — если его нет, пункта в меню не будет.

---

## Что можно собрать: табы и виджеты

Дашборд состоит из **табов**, внутри каждого таба — **виджеты-чарты** на 12-колоночной сетке. Каждый виджет тянет данные из метрик тенанта за выбранный период.

- **Табы** — как вкладки: несколько дашбордов в одном месте. Добавить — `+` в баре табов, переименовать — двойной клик по названию, закрыть — крестик (последний таб закрыть нельзя). Первый таб по умолчанию называется `Cool Dashboard`.
- **Виджеты** — двигаются и меняют размер мышкой (перетаскивание за хедер, ресайз за угол). При наложении соседние виджеты автоматически сдвигаются вниз, не перекрываются.
- Раскладка **не сохраняется автоматически** — после правок в тулбаре появляется `Save`; рядом `Discard` откатывает несохранённые изменения к последнему сохранённому состоянию.

## Как добавить чарт-виджет

Кнопка **`New chart`** в тулбаре открывает диалог нового виджета. Задаёшь:

- **Title** — название карточки (если пустое, подставится имя типа).
- **Chart type** — тип визуализации (см. ниже).
- **Metric(s)** — одна или несколько метрик из каталога тенанта. Типы `Number` и `Rank list` работают только с одной метрикой.
- **Group by** — группировка (страна, кампания, дата и т.п.) из того же набора, что и в отчётах Drill Down. Для `Number` и `Funnel` группировка не применяется; остальные типы её используют.
- **Color** — цвет акцентной полоски карточки.
- **Compare** — добавить сравнение со встречным периодом (доступно не для всех типов, см. ниже).

Тип и метрику можно менять и прямо на карточке — через инлайн-теги на хедере виджета, не открывая диалог. Там же в меню карточки: `Duplicate` (копия виджета), `Remove`, перезагрузить данные.

### Типы чартов

Доступные типы (сгруппированы в диалоге):

- **Column** / **Stacked** — столбчатые (обычный и с накоплением).
- **Line** / **Area** — линейный и с заливкой.
- **Pie** / **Treemap** — доли и вложенные площади.
- **Number** — одно число (тотал метрики), с мини-спарклайном.
- **Top Table** / **Rank list** — таблица-топ и рейтинг-список.
- **Funnel** — воронка.

`Column`, `Line`, `Stacked`, `Area` — временные ряды: по оси времени раскладываются автоматически, а выбранная группировка становится разбивкой серий поверх времени. **Compare** поддержан на `Line`, `Area`, `Column`, `Stacked`, `Number`, `Top Table` — на остальных типах тумблер выключается.

## Старт с шаблона: пустой таб предлагает готовые дашборды

Когда в активном табе нет виджетов, вместо пустого поля показывается **пикер шаблонов** — набор преднастроенных дашбордов под вертикаль плюс карточка `Empty dashboard` (начать с нуля).

Шаблоны сгруппированы по вертикалям: sweepstakes, gambling, nutra, finance. Каждый несёт готовый набор чартов с плейсхолдер-метриками (условными именами вместо конкретных UUID).

При выборе шаблона открывается диалог маппинга: плейсхолдеры метрик и группировок сопоставляются с метриками **твоего** тенанта. Система пытается подставить совпадения по имени автоматически; незамапленные слоты нужно выбрать вручную — пока не заполнены все, кнопка `Apply template` неактивна. После применения чарты со своими позициями раскладываются в активный таб.

## Фильтры и период: тулбар дашборда

Тулбар управляет тем, за что и по каким срезам считаются все виджеты таба:

- **Период** — пресеты (Today / Yesterday / This week / Last week / This month / Last month) или произвольный диапазон. Меняет данные всех виджетов.
- **Compare** (страничный) — включает встречный период для всего таба сразу; можно и точечно на отдельном виджете.
- **`Filters`** — страничные фильтры в диалоге `Page filters`: применяются ко всем чартам таба и складываются по AND с пер-чартовыми фильтрами.
- **Cross-filter** — тумблер (по умолчанию включён): фильтрация **интерактивно, кликом по данным**. Кликаешь строку в `Top Table` / `Rank list` или точку/сектор чарта — это значение уходит в общий фильтр страницы, и **все** виджеты таба пересчитываются по нему. Повторный клик по тому же значению снимает его; при выключенном тумблере клики по данным не фильтруют. Пока стоит хотя бы одно значение, в тулбаре видна красная кнопка `Reset Filters` со счётчиком — сбрасывает все разом.
- **Event Attribution** — тумблер атрибуции конверсий по времени события.
- **Auto-refresh** — авто-перезагрузка данных каждые 30 секунд; рядом кнопка ручного обновления.

Набор доступных метрик и группировок берётся из каталога тенанта — у разных тенантов он разный.

## Как поделиться дашбордом: share-код

Кнопка `Share` в тулбаре генерирует **код-строку** для активного таба (нужен хотя бы один виджет). Код можно скопировать и передать; на другой стороне его вставляют в том же диалоге `Share` — и таб импортируется как новая вкладка со всеми виджетами.

- Код — короткая строка из 8 символов.
- У кода есть срок жизни: просроченный код при вставке даёт `Code expired`, несуществующий — `Code not found`.
- Ранее выпущенные коды видны списком `My codes` в диалоге (имя, число чартов, дата) — их можно удалять.

*Импорт создаёт новый таб с копиями виджетов; исходный дашборд у автора не меняется.*

## Кому доступен BI Builder

BI Builder доступен **не всем тенантам** — включается на стороне аккаунта. Если для тенанта фича не активирована, виджеты вместо данных показывают ошибку вида `BI API not enabled for this account`. Сама страница при этом открывается (по permission `analytics.charts-builder`), но данные не грузятся, пока доступ не включён.
