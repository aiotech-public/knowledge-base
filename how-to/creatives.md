# Creatives — креативы с картинками и видео, обложка, кадрирование и видеоредактор

**`Content → Creatives` (`/app/landers-creatives/creatives`, только ERP) — медиатека рекламных креативов: картинки и видео, сгруппированные в креативы, с автоматической обработкой файлов, кадрированием видео под форматы площадок и встроенным видеоредактором.** Раздел открывается с правом `content.creatives.view`; добавлять, править, кадрировать, ставить постер, менять главный файл и работать в видеоредакторе — с `content.creatives.edit` (как выдаются права — [how-to/permissions.md](permissions.md)). В MTK раздела нет.

Креатив на лэнд и в кампанию не подставляется: его загружают и готовят под форматы площадок. Статистику по визитам он при этом собирает — если в ссылке объявления передан его UUID в параметре `creative_uuid` (секция «Статистика креатива» ниже). Прямая ссылка на любой файл креатива — в колонке `URL` списка `Show creative items` (скрыта по умолчанию, включается в настройках таблицы). Готовые картинки генераций (`Content → Generations`) в Creatives сами не попадают ([how-to/generations.md](generations.md)).

Как ещё спрашивают: «куда залить крео», «медиатека», «библиотека креативов», «видео для рекламы», «нарезать видео под рилсы / сторис», «сделать 9:16 из горизонтального видео».

## Что такое креатив в AIO — главный файл и вариации

**Креатив — одна идея (концепт) с набором файлов: главный файл и его вариации.** Главный файл — обложка креатива в галерее и его превью; остальные файлы — вариации того же креатива: другие форматы, кадрирования, экспорты из редактора. У файла есть тип (картинка или видео), формат по соотношению сторон и статус обработки.

Тип креатива AIO выводит из файлов сам: `Images` — только картинки, `Video` — только видео, `Images and video` — и то и другое. Рядом показываются счётчики `N files` / `N videos`.

Формат файла определяется по его размерам, с допуском 3 %: `1:1 Square`, `4:5 Portrait`, `2:3 Portrait`, `9:16 Vertical (Stories / Reels)`, `16:9 Landscape`, `1.91:1 Wide (Link)`; всё прочее — `Other`.

Файлы креатива открывает `Show creative items` в контекстном меню (право `content.creative-items.view`): список вариаций с их собственными действиями — `Make main`, `Set poster`, `Crop video`, `Reprocess file`, архив.

## Как добавить креатив — `Add creatives`

**Креатив создаётся кнопкой создания в разделе `Creatives` (форма `Add creatives`): имя, описание, гео, языки, теги и файлы.**

1. `Name` — имя креатива (обязательно).
2. `Description` — о чём креатив.
3. `Countries` и `Languages` — гео и язык креатива, как у лэндов; по ним работают фильтры раздела.
4. `Tags` — теги для поиска и отбора.
5. `Files` → `Add files` — картинки и видео, до 1 GB на файл (`Up to 1 GB per file`). Без файлов форма не сохраняется (`Add at least one file`).
6. `Save`.

Файлы сразу появляются в креативе, и каждый обрабатывается отдельно — секция «Статус обработки файла» ниже. Правка креатива (`Edit creative` в контекстном меню) открывает ту же форму: поля меняются, новые файлы добавляются к уже загруженным.

## Какие файлы принимает Creatives — картинки, видео, лимит 1 GB

**В креатив загружаются только картинки и видео, до 1 GB каждый файл.** Файл другого типа форма загрузки не принимает (`This type of file is not allowed`), файл больше лимита — тоже (`<имя>: file size exceeds the limit - 1 GB`).

AIO приводит файлы к одному виду, который подходит и для страницы, и для загрузки в рекламный кабинет:

- **JPG и PNG** остаются как есть.
- **WebP, AVIF, TIFF, BMP** переводятся в JPG без уменьшения (ширина — до 4096 px); оригинал сохраняется. Если перевести не удалось, остаётся оригинал с пометкой `Conversion failed, the original file is used: …`.
- **Видео не в MP4 с H.264** (MOV, HEVC с iPhone, WebM и т. п.) перекодируется в MP4 (H.264) — секция ниже.

Для каждого видео AIO сам снимает постер (кадр-обложку), короткий беззвучный клип для превью при наведении в галерее и длительность. Клик по видео в галерее открывает плеер с полным файлом.

### Видео в MOV / HEVC / WebM — AIO сам переводит в MP4 (H.264)

**Видео, которое не является MP4 с кодеком H.264, перекодируется в MP4 (H.264) в том же файле креатива; пока идёт конвертация, у файла статус `Converting to MP4 (H.264)...`.** Постер и превью снимаются с исходника сразу, поэтому файл в галерее виден ещё до конца конвертации. Исходный файл сохраняется.

Если перекодировать не удалось, файл остаётся рабочим на исходнике: в карточке файла — `Conversion failed, the original file is used: …`, в колонке `Status` списка `Show creative items` — `ready: Not converted to MP4, original kept: <причина>`. Такой файл в плеере браузера и в рекламном кабинете может не открыться — лучше залить видео заново в MP4.

## Статус обработки файла: `Processing…`, `Processing failed`, `Retry`

**Каждый файл обрабатывается отдельно: пока идёт обработка — `Processing…`, при ошибке — текст причины (без причины — `Processing failed`) и кнопка `Retry` в форме правки креатива.** Один упавший файл не ломает остальные.

Повторная обработка — `Retry` в форме креатива или `Reprocess file` в меню файла («Process the file again: dimensions, poster and preview clip.»). Свой постер, загруженный вручную, повтор не трогает. Если видео не обработалось за отведённое время, статус — `Video processing timed out`.

Статус самого креатива сводит статусы файлов:

- `Processing N file(s)...` — часть файлов ещё в обработке;
- `N file(s) failed` / `All files failed` — есть файлы с ошибкой;
- `Everything is fine` — всё готово.

У того, кто загрузил файл или запустил его обработку, статусы обновляются на странице сами; остальным пользователям новый статус виден после обновления страницы.

### Бейдж `Duplicate` — этот файл уже загружен в тенант

**`Duplicate` на файле значит, что точно такой же файл уже есть в этом тенанте; подсказка называет UUID уже загруженного файла (`This file is already uploaded to the tenant: <uuid>`).** Загрузку дубль не блокирует — бейдж нужен, чтобы не держать один и тот же креатив в разных местах. Сравниваются сами файлы, а не имена: переименованная копия тоже получит бейдж.

## Главный файл креатива — `Make main`

**`Make main` в меню файла (`Show creative items`) делает файл главным: он становится обложкой и превью креатива, прежний главный остаётся вариацией.** Подтверждение — `Make this file the main one?`.

Готовый файл становится главным сразу. Файл, который ещё обрабатывается или рендерится, переключится, когда будет готов — до этого у него метка `will be main`, у текущего главного — `Main`. Пункта нет у архивных, упавших и уже главного файлов.

## Обложка видео — `Set poster`: кадр из видео или своя картинка

**`Set poster` задаёт постер (обложку) видео: кадр из самого видео (`Video frame`) или своя картинка (`Own image`).** Для кадра поставьте видео на паузу на нужном моменте — постер берётся с этого времени и появляется через несколько секунд.

В меню креатива пункт есть, когда обложка креатива — видео или видео в креативе одно; иначе постер ставят конкретному файлу через `Show creative items`. У креатива без видео — `This creative has no video — a poster can be set only for a video.`

Автоматический постер AIO снимает при загрузке сам; свой постер повторная обработка файла не перезаписывает.

## Как обрезать видео под 9:16, 1:1, 4:5 — `Crop video`

**`Crop video` (подменю `Video` в меню креатива или меню файла) кадрирует готовое видео в формат и создаёт новый файл в том же креативе; исходник не меняется.** Форматы — `9:16 Vertical (Stories / Reels)` (по умолчанию), `1:1 Square`, `4:5 Portrait`, `2:3 Portrait`, `16:9 Landscape`, `1.91:1 Wide (Link)`.

1. Выберите формат.
2. Перетащите рамку на ту часть кадра, которую нужно оставить.
3. `New file name` — по желанию.
4. `Make the result the main file` — включено по умолчанию: кадрированный файл станет главным, когда дорендерится, исходник останется вариацией.
5. `Crop`. Новый файл появится через некоторое время (`Cropping started — the new file will appear shortly`).

С креатива кадрируется его главное видео (или единственное). Кадрирование из меню файла всегда делает результат главным — переключателя там нет. Видео, которое ещё обрабатывается, кадрировать нельзя.

## Видеоредактор креатива — черновики и таймлайн (`Video editor`)

**`Video editor` в подменю `Video` меню креатива открывает редактор: видео креатива собирается на таймлайне и экспортируется в нужные форматы новыми вариациями.** Пункт есть у креатива с видео.

Работа идёт в черновиках (`Drafts`): `New draft` создаёт черновик, в котором главное видео креатива — первый клип. Черновиков у креатива может быть несколько; удаляются они `Delete draft`.

На таймлайне — дорожки видео, текста, картинок и звука. Клипы двигаются и обрезаются, дорожки добавляются (`Track`) и меняются слоями (`Layer up` / `Layer down`); есть `Undo` / `Redo`. В панели `Media` — готовые файлы креатива: `Add to timeline` ставит файл клипом, а у видео `Add as a layer (picture in picture)` — слоем поверх основного видео.

Черновик сохраняется сам (`Saved` / `Unsaved changes` / `Saving…`). Если тот же черновик правят в другой вкладке, редактор пишет `The project was changed in another tab.` и предлагает `Load the latest version`.

Формат сцены переключается над превью (`Video size`). В `Project settings` — `Background`: фон вокруг видео, вписанного в кадр.

### Текст, музыка, логотип и картинка-в-картинке в видеоредакторе

**`Add text` добавляет текстовый клип, `Music` — звуковую дорожку из своего файла, `Logo` — картинку-логотип поверх видео.** Загруженные музыка и логотипы остаются в панели `Uploaded`, их можно поставить на таймлайн ещё раз.

Свойства выбранного клипа (`Clip properties`):

- **видео** — блок `Frame`: `Fill the frame` (заполнить кадр) или `Fit inside` (вписать); `Separate frame for <формат>` — своё положение кадра для конкретного формата экспорта; `Zoom` (при `Fit inside` — `Picture size`), положение `X` / `Y`; блок `Sound` — `Volume`;
- **текст** — `Font`, `Weight`, `Size`, `Color`, `Background`, `Padding`, `Align`, `Width`; эмодзи в рендере не выводятся (`Emoji are not rendered.`);
- **картинка** — `Size`, `Opacity`;
- **звук** — `Volume`, `Fade in, ms` / `Fade out, ms`.

Текст и картинка ставятся на место перетаскиванием прямо в превью (`Drag the layer right in the preview.`).

### Субтитры из речи — `Subtitles` → `Generate`

**`Subtitles` → `Generate` распознаёт речь в видео-клипах черновика и кладёт её текстовой дорожкой `Subtitles`; повторный запуск заменяет прежнюю дорожку.** Когда готово, редактор сообщает `Subtitles added: <N>`; при сбое — `Could not generate subtitles`.

`Language` — язык речи: `Auto` берёт первый язык из поля `Languages` креатива; если языки не заданы или язык не поддерживается, распознавание идёт на языке по умолчанию, а не на языке ролика. Поэтому заполните `Languages` или выберите язык вручную. Клипы без звука или с выключенной громкостью пропускаются. Титры делятся на короткие фразы и дальше правятся как обычный текст на таймлайне.

### Превью и экспорт из редактора в несколько форматов — `Render preview`, `Export`

**`Export` → `Export formats` → `Export` рендерит черновик в каждый выбранный формат отдельной вариацией креатива (`Export started: <N> variations will appear shortly`).** По умолчанию отмечен формат превью. Готовые вариации появляются в креативе сами и дальше живут как обычные файлы: их можно сделать главными, кадрировать, взять ссылку из колонки `URL`.

`Render preview` собирает быстрое превью 480 px — показывает, как будет выглядеть экспорт, без создания файла (`How the export will look (480 px)`). Черновик без клипов не рендерится (`Project is empty: add a video clip`).

## Как найти креатив — галерея, гео, язык, тип, формат, теги

**Раздел по умолчанию открыт галереей: обложка, тип, счётчики файлов, флаги стран; видео при наведении проигрывает короткий клип, по клику открывается плеер.** Переключатель вида сверху переводит раздел в обычную таблицу.

Фильтры: гео (`Countries` креатива), `Languages`, `Tags`, `Type` (`Images` / `Videos` / `Mixed`), `Format` (есть файл этого формата), архив. `Format` в тулбар не вынесен — он в `Settings` → `Table settings` → `Filters`. В табличном виде колонки `Type` и `Languages` скрыты по умолчанию и включаются там же, в `Columns`. Креативы раскладываются по папкам (кнопка папок в верхней панели, права `content.creatives.folders.*`; `Assign to folder` — с `content.creatives.edit.assign-folder`) — [how-to/permissions.md](permissions.md). Чем Creatives отличаются от Content Library и где в разделе Content лежат Uploaded files и CDN files — [models/content-library.md](../models/content-library.md), [reference/ui-map.md](../reference/ui-map.md).

## Статистика креатива — визиты, конверсии и деньги по ссылке с `creative_uuid`

**Список `Content → Creatives` показывает у каждого креатива метрики трафика за выбранный период — визиты, конверсии, деньги; считаются они по визитам, в ссылке которых пришёл UUID этого креатива в параметре `creative_uuid`.** Частые формулировки: «статистика по креативу», «сколько лидов дал креатив», «какой крео лучше», «аналитика в медиатеке».

- **Привязка.** В ссылку объявления добавьте `creative_uuid=<UUID креатива>`; UUID — в колонке `UUID` (скрыта по умолчанию, `Settings` → `Table settings` → `Columns`). Несколько креативов передаются через запятую — каждый занимает свою позицию в визите. Как AIO читает параметр и разрез `Creative #N` в отчётах — [how-to/analytics.md](analytics.md).
- **Позиция `#N`.** Строка считает визиты, где креатив стоит на позиции, выбранной жёлтой кнопкой `#1` в тулбаре; клик переключает `1 → 2 → 1`. Значение общее с `Content → Landings` и `Tracker → Destinations` ([reference/ui-common.md](../reference/ui-common.md)): креатив, который в ссылке идёт вторым, при `#1` показывает нули.
- **Период и пустые строки.** Период — кнопкой дат в тулбаре; кнопка-фильтр без подписи прячет креативы без трафика за период.
- **Пресет.** Набор колонок и фильтров сохраняется пресетом типа `Table Creatives`.

### Метрики в галерее креативов — `Show analytics` и крупные карточки лучших по Revenue

**В галерее метрики креатива спрятаны под кнопкой `Show analytics` / `Hide analytics` в карточке; переключатель один на все карточки и общий с сеткой других таблиц (например `Content → Landings`), запоминается в этом браузере.** В карточке видны метрики, чьи колонки включены в настройках таблицы.

Карточки лучших креативов по Revenue крупнее — на две колонки сетки: это топ-10 % креативов с Revenue больше нуля, минимум одна и не больше шести карточек. Выделение работает, когда колонка Revenue видна и в сетке помещаются хотя бы три колонки; от сортировки таблицы оно не зависит.

## Кто может открыть и править креатив — владелец, шара, папка, `No access to this object`

**Список креативов видят все с правом `content.creatives.view`, а открыть креатив, править, кадрировать, ставить постер, менять главный файл и работать в редакторе можно только при доступе к самому креативу.** Доступ дают: владелец (кто создал креатив, колонка `Owner`) и его команда по иерархии и настройкам команды, шара (`Share` с ролью `Viewer` или `Editor`, в том числе через шару папки с креативом) и полный доступ к тенанту (роль `Owner` или `Admin`) — модель уровней в [models/permissions-model.md](../models/permissions-model.md). Ветки `Scopes` / `Editor Scopes` на креативы не действуют.

Без доступа действие отбивается `No access to this object (view level required)` при открытии или `(edit level required)` при сохранении. У креатива с пустой колонкой `Owner` владельца нет: его открывают и правят пользователи с полным доступом, они же назначают владельца (`Change ownership`) или делятся креативом.
